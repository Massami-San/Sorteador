# Sorteador de Números

Uma aplicação simples para sortear um número inteiro dentro de um intervalo definido pela pessoa usuária. O projeto foi criado para praticar HTML, CSS e JavaScript, com uma interface adaptável a diferentes tamanhos de tela.

## Funcionalidades

- Definir os valores mínimo e máximo do intervalo.
- Sortear e exibir um número dentro do intervalo informado.
- Usar a página em telas de computador e dispositivos móveis.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Informe os valores mínimo e máximo e clique em **Sortear**.

Não é necessário instalar dependências ou iniciar um servidor.

## Arquivos do projeto

- `index.html` — estrutura da página.
- `Style.css` — estilos e layout responsivo.
- `Script.js` — lógica do sorteio.
